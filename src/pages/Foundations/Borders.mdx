# Borders

<Lead>
  Borders define separation, grouping and interaction boundaries. They should
  support structure without creating visual noise.
</Lead>

Use border roles instead of raw greys.

<ReferenceTable
  columns={["Token", "MUI role", "Purpose", "Typical use"]}
  rows={[
    [
      <code>--ds-border-subtle</code>,
      <>
        <code>divider</code> or <code>border.subtle</code>
      </>,
      "Default quiet border",
      "Dividers, table separators, low-emphasis boundaries",
    ],
    [
      <code>--ds-border-emphasis</code>,
      <code>border.emphasis</code>,
      "Elevated interaction or emphasis",
      "Inputs, highlighted cards, panels, tables, important grouping",
    ],
    [
      <code>--ds-border-strong</code>,
      <code>border.strong</code>,
      "Maximum border contrast",
      "Hover states, active regions, selected neutral items",
    ],
  ]}
/>

MUI's native `divider` role and DiamondDS `border.subtle` use the same value.
Use `divider` where an MUI component expects it, and `border.subtle` when
writing DiamondDS border styles directly.

<DoDont
