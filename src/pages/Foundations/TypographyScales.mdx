## Typography scale

DiamondDS provides a shared typography scale that underpins all typography
variants.

    [<code>--ds-font-size-900</code>, "2.125rem (34px)"],
    [<code>--ds-font-size-1000</code>, "3rem (48px)"],
    [<code>--ds-font-size-1100</code>, "4.5rem (72px)"],
  ]}
/>

Use typography variants directly in most cases. Font size tokens are mainly for
building reusable components, defining typography variants and keeping the scale
consistent across the design system.

Avoid applying arbitrary font sizes when an existing variant already
communicates the right hierarchy and meaning.
