Prefer layered surfaces and borders over heavy shadows.

MUI's default elevations come from Material 2, where elevation meant shadow
depth. DiamondDS takes inspiration from Material 3 instead: floating surfaces
stay at moderate tones, and the scrim and shadow carry the sense of lift.

The drop shadow (`--Paper-shadow`) is off by default on every Paper-based
surface: Card, Accordion and plain Paper. It is restored only on true overlays
that need to float above page content: Dialog, Menu, Select, Popover,
Autocomplete's listbox, temporary Drawers and Snackbar. Tonal elevation, the
`--ds-elevation-*` background tint, still applies everywhere regardless of
shadow.

If tone alone isn't enough separation for a flat surface, use
`variant="outlined"` rather than a manual border override. See
[Borders](/foundations/borders).

## Surface roles or elevation

Choose by what the surface represents, not by how it looks. The surface roles
themselves are listed under _Surface model_ on
[Colours, Surfaces and states](/foundations/colours/surfaces_and_states).

- `surface.subtle` and `surface.strong` are fixed, static roles for content that
  stays in normal page flow, such as secondary panels, nested containers and
  selected regions. There is no range, so pick whichever of the two gives enough
  contrast.
- Paper `elevation` applies only to Paper-based components: Card, Dialog, Menu,
  Select, Popover, Drawer, Snackbar and Autocomplete. There the number also
  decides whether a real shadow shows. Don't use it to tint an arbitrary `Box`
  for layout grouping.

`surface.subtle` and `surface.strong` are tuned to land on the same tone as
elevation 7 and 16. A grouped panel and a Card at a similar elevation therefore
read as the same visual weight by design. That is shared vocabulary between the
two systems, not a reason to use one in place of the other.

## Component notes

- Use `raised` for interactive cards rather than a manual `elevation` value. The
  theme gives it a real shadow to match.
- Autocomplete's listbox is themed to match Menu, Select and Popover
  automatically.
- When using `AppBar` as a top nav bar, add a bottom border through `sx`.
- A custom `backgroundColor` on `Paper`, set through `sx`, overrides the tonal
  elevation tint. That is useful for semantic surfaces such as an error panel,
  but it means `elevation` then only affects the shadow, not the colour.
